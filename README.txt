FROST RUNNER - COMPLETE UNITY PROJECT
=====================================

HOW TO OPEN
1. Unzip this folder.
2. Open Unity Hub > Add > "Add project from disk" and pick the FrostRunnerUnity folder.
   (Any Unity 2021.3 LTS or newer works, including Unity 6. If Hub says the
   editor version is missing, choose one you have installed and let it upgrade.)
3. When the project opens, double-click Assets/Scenes/Main.unity (optional - the
   game also starts automatically in any scene).
4. Press Play.

No art or sound files are needed; everything is generated by the script.

CONTROLS
  Jump (press again in the air to double jump): Space / Up / W / Enter / click / tap
  Move:       Left, Right  or  A, D
  Fast drop:  Down  or  S
  Pause:      P or Esc
  Sound:      M (on/off)

TWEAKING
  Assets/Scripts/FrostRunner.cs
  - Gravity, jump power, speed: Step() and Jump()
  - Obstacle and coin chances: Gen()

BUILD
  File > Build Settings > pick a platform > Build. Mouse clicks and touch jump.
